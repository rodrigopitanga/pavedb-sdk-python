# Cited RAG

Run from an SDK checkout after installing `pavedb` alongside this SDK:

```bash
PYTHONPATH=examples python examples/7-cited-rag/cited_rag.py
```

The program seeds and removes a temporary local store. It prepares evidence and a
citation check only; bring your own model at the marked seam. This book-derived
example is MIT-licensed; see `examples/LICENSE`.
